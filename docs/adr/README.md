# Architecture Decision Records

This directory records important architectural decisions for Logic Co-Producer.

Each ADR should state the decision, status, evidence, consequences, alternatives, and what would cause the decision to be revisited. Decisions that depend on an unresolved Logic behavior are marked **Proposed / POC-gated** rather than presented as solved.
